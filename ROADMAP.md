# خارطة الطريق

الخارطة مرتبة بالأولوية لا بالتواريخ، وقد يتغير ترتيبها بحسب ما تحتاجه الجهات. لاقتراح بند، افتح [بلاغًا](https://github.com/Juman-ai/juman-chat/issues).

## الآن

- ربط الموافقة بمستخدم مصادَق، مع سجل يذكر من وافق ومتى.
- حفظ الإجراءات المعلّقة في قاعدة بيانات بدل الذاكرة.
- استضافة الخطوط محليًا ليعمل البناء دون إنترنت.
- رابط تخطٍّ إلى المحتوى، وفحص كامل للتنقل بلوحة المفاتيح.
- شاشة ترحيب من إعدادات الجهة (الاسم، نص الترحيب، أسئلة مقترحة).
- إخفاء زر الإرفاق تلقائيًا (NEXT_PUBLIC_ENABLE_ATTACHMENTS).
- عرض المصادر التي استُخدمت فعلًا في الإجابة فقط.

## التالي

- تغيير ارتفاع الإطار (iframe) تلقائيًا بحسب المحتوى.
- مبدّل لغة بين العربية والإنجليزية داخل الواجهة.

## لاحقًا

- موصّلات لأنظمة الجهات حسب الطلب، بدءًا بـ Drupal.
- حزمة تضمين جاهزة لمواقع Drupal.

# Roadmap

Ordered by priority, not by date. The order may change with what entities need. To propose an item, open an [issue](https://github.com/Juman-ai/juman-chat/issues).

## Now

- Bind approval to an authenticated user, with a log of who approved and when.
- Store pending actions in a database instead of memory.
- Self-host fonts so builds work offline.
- Skip-to-content link and a full keyboard-navigation pass.
- Welcome screen from the entity's configuration (name, welcome text, suggested questions).
- Hide the attach button by default (NEXT_PUBLIC_ENABLE_ATTACHMENTS).
- Show only the sources the answer actually uses.

## Next

- Resize the iframe automatically to fit its content.
- An in-app switch between Arabic and English.

## Later

- Connectors for entity systems when an entity requests them, starting with Drupal.
- A ready-made embed package for Drupal sites.
