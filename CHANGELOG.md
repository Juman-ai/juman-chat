## [0.1.0] - 2026-11-16

First public release (preview).

### Added

- Arabic-first, right-to-left chat interface built on assistant-ui, with the Juman brand layer in one file.
- Source link under every answer, and a distinct "not covered" state.
- Human approval card for proposed actions, enforced by the backend.
- Demo backend (FastAPI) returning canned answers.
- Arabic and English UI strings in one file.
- Bilingual README, infographics and screenshots.
- Support, contribution, governance and roadmap documents.
